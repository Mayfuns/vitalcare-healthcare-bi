# VitalCare Dashboard

This folder contains the three final Power BI report pages used in the VitalCare healthcare analytics project.

## Dashboard pages

1. **Healthcare Overview** — admissions, revenue, patient volume, average length of stay, readmissions and demographic performance.
2. **Clinical and Patients Analysis** — patient outcomes, recovery, mortality, bed occupancy and diagnosis-level readmissions.
3. **Financial Analysis** — revenue, costs, profit, margin, doctor performance and revenue by age group.
